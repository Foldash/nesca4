Готовый предпросмотр интерфейса NESCA 4 для Windows x64.

Скачай **NESCA4-UI-Windows-x64.zip**, распакуй весь архив и запусти **nesca4-ui.exe** из полученной папки. Qt и библиотеки среды выполнения включены; установка инструментов разработки не требуется.

Это версия для проверки оформления, вкладок и полей. Сетевое ядро не подключено, кнопки сканирования отключены.

Перед публикацией выполняются регрессионные тесты и проверка распакованного архива на Windows с исключёнными путями установленного Qt. Отдельно приложены контрольная сумма SHA256 и снимок окна Windows.
