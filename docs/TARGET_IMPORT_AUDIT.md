# Безопасность импорта адресов

Дата: 2026-11-21.

Старый `fileLoader` считал строки через fgets, затем независимо читал их через
getline с другими правилами комментариев. Число записей могло превышать размер
вектора, после чего выполнялось обращение за его границы. Разбиение IPv4
индексировало октеты без проверки их количества. Память выделялась заранее
через вложенные new[], а освобождалась по числу успешно разобранных записей:
ошибка посередине оставляла часть выделений без очистки. Маска CIDR не
ограничивалась диапазоном 0..32. Тот же небезопасный разбор повторялся в ручном вводе.

Теперь `TargetList` проверяет текст за один ограниченный проход и возвращает
полностью готовый план либо исключение с номером строки. Чтение ограничивается
до добавления очередного байта в строку; длинная строка не выделяется целиком
перед проверкой. Лимиты по умолчанию: 16 МиБ, 4096 байт на строку и 100000 записей.
Проверяется отмена, состояние потока и отсутствие пустого плана. При ошибке
частичный результат не возвращается. В журнал не попадает недоверенный текст
файла. Адаптер принимает только обычный файл и использует UTF-8 путь.

Загрузчик приложения подготавливает два vector<array<unsigned int,4>> и
публикует их через swap только после успешного разбора и всех выделений.
Исчезли вложенные raw-выделения и зависимость очистки от flCounter. Ручной ввод
использует тот же парсер. CIDR /0 и /32 обрабатываются без сдвига на ширину
типа, количество адресов считается в uint64_t. Счётчики циклов MainStarter
расширены до uint64_t, чтобы инкремент последнего IPv4 на Windows не замыкался
в ноль. Это не проверка корректности всего старого планировщика.

Порядок записей, перекрытия и повторы сохраняются. Убрано безусловное
перемешивание строк во время чтения, которое выполнялось даже при выключенной
настройке. Настройка последующего перемешивания в сеансе сохранена.
Комментарии допускаются только отдельной строкой; UTF-16 и частично верные
строки отвергаются. Строка RESTORE_IMPORT_SESSION не является адресом:
восстановление использует обычные диапазоны из tempIPLst.bk.

Проверки не открывают сетевые соединения:

- `target-list-regression`: границы /0, /31, /32, IPv4 0 и UINT32_MAX,
  несколько диапазонов, BOM/CRLF/комментарии, повреждённые записи, ограничения,
  ошибки потока, отмена, отсутствие частичной замены, 10000 обратимых
  преобразований адресов и граница 100000 записей.
- `legacy-import-check`: временный путь с кириллицей и пробелами, несколько
  записей, неверная вторая строка, сохранение прежнего плана, повторная загрузка,
  каталог, отсутствующий и пустой файл. Вызывается только загрузчик.
- Linux: полная сборка и CTest 9/9. Отдельный разборщик прошёл ASan/UBSan;
  detect_leaks=0 из-за ограничений среды, проверка утечек LSan не выполнялась.

Сетевой сеанс не запускался. Старый IPRandomizer, разбор ответов, общие данные
GUI и счётчики прогресса требуют отдельного аудита. Полное приложение Windows
на этом этапе не собиралось; Windows workflow проверяет UI и чистые модули.
